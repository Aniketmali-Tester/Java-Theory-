**2.JDK (Java Development Kit) ((current version jdk-26))**



Definition:

The JDK is a software development kit used to develop Java applications. It provides all the tools and libraries necessary for developing and running Java programs.



3.Components:

==>JRE (Java Runtime Environment): Included within the JDK, the JRE allows you to run Java applications.

==>Development Tools: Includes a variety of tools for developing, debugging, and monitoring Java applications (e.g., javac, java, javadoc, jdb).





4.JRE (Java Runtime Environment):

Definition:

 ==>The JRE is a subset of the JDK that provides the libraries, Java Virtual Machine (JVM), and other components required to run applications written in Java.

 ==>It does not include development tools like compilers or debuggers.



5.Components:

JVM (Java Virtual Machine): The core part of the JRE that runs Java bytecode.

Class Libraries: Pre-written Java classes that provide commonly used functionality.

Definition:

==>The JVM is an abstract computing machine that enables a computer to run Java programs.

==>It is platform-independent and converts Java bytecode into machine code suitable for the host machine.
