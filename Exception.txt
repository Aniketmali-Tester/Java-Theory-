EXCEPTION HANDLING IN JAVA
==========================

Definition:
Exception Handling is a mechanism in Java used to handle runtime errors
so that the normal flow of the program can continue without termination.

OR

Exception Handling is the process of handling unexpected events
(runtime errors) that occur during program execution.

Purpose:
1. Prevent abnormal program termination.
2. Maintain the normal flow of the program.
3. Handle runtime errors gracefully.

Keywords Used in Exception Handling:
1. try       - Contains code that may cause an exception.
2. catch     - Handles the exception.
3. finally   - Executes whether an exception occurs or not.
4. throw     - Used to explicitly throw an exception.
5. throws    - Declares exceptions that a method may throw.

Syntax:

try {
    // risky code
}
catch(Exception e) {
    // exception handling code
}
finally {
    // cleanup code
}

Real-Time Example:
ATM transaction, file handling, database connection, and user login
validation are common examples where exception handling is used.
