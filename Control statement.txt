Control statement:

1.what is use of control statement?

        ==>Control statement are mainly use to control flow of program execution.
        ==>Every Programming Language uses control statement to control the flow of execution.
        ==>JAVA control statement classified into 2 types:
               1)Decision making statement
               2)Looping satements

   Control statements
   
                            
   1.Decision making               

         *)if-else
         *)Switch

   2.Looping
          
          *)for loop
          *)while loop
          *)do-while loop
          *)break & continue



2.Explain the use of decision making statements?
            
            ==>Decision making statements are use to apply conditions or restriction on program data.
            ==>In java we can use two statements in order to apply conditions and restriction.
                 
                     a)if-else statement
                     b)switch statement
            ==>It is possible to apply various conditions by using if-else or switch statement.
