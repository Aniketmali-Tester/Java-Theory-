5.Explain unary operators?


    ==>Unary operators are mainly use to perform operations on single variables.
    ==>unary operations can be done by::-
        
         1)Increment

                 Ex:(++=>+1)

                    a)Post Increment
                    b)Pre Increment
         
          2)Decrement
                    
                 Ex:(--=>-1)

                    a)Post Decrement
                    b)Pre Decrement
    

   A)Post Increment::
        
          Post Increment means First use current value inside the expression and then increment original value by +1.

   B)Pre Increment:
          
          It means First increase the original value by +1 and then use inside the expression.

   C)Post Decrement:
          
           It means first use the current value inside the expression and decreases the original value by -1.

   D)Pre Increment:
          
           It Means First decreases the original value by -1 and then use inside the expression.
