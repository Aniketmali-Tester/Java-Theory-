8)What is D/B Parameterized and Non-Parameterized?

            ==> If Method Accepts Inputs Parameters then Known as Parametrized Method.
            ==> The Method Which Does Not Accepts Input Parameters Known as non-parametrized Method.
            ==> If Method Parametrized then it can pass run time data.
            ==> If Method is non-parametrized than it can't pass Run time Data.
