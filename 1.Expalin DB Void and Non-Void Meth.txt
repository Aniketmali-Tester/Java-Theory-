&#x20;       ==>If Method is **Having Return Type as a Void It Means we can't transfer the Data** From that Particular Method.

&#x20;       ==>To T**ransfer the Data** **from one method to another Method** we have to **declare method without using void** **Return Data type** Which is also **known as Non-void Method**.



2.How Transfer the Data one method to another method?

&#x20;        

&#x20;       ==>It's Possible to transfer the data from **one method to another method by using Return Statement**.

&#x20;       ==>**Return Statement Should be last** statement of method body.

&#x20;       ==>It's Possible to declare multiple return Statement Inside the Single Method.

&#x20;       ==>If method is having Return Statement then Be have to provide appropriate Data type as Return type.

6.Why main method is having return type as void?



&#x20;           ==>Main Method is the internal method is responsible for Execution.

&#x20;           ==>Execution starts with main method and ends with method so it is not possible to a return value from main method.

&#x20;           ==>Because of all these reasons main method having return type as void.
