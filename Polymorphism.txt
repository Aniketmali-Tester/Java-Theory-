         *)In other words Polymorphism is the process of creating object with multiple Behaviours.

         *)Polymorphism Mainly claasified Into two types::
     
                     ==>Compile Time polymorphism
                     ==>Run time Polymerphism

2.what is mean by Method overloading?

       *)The process of Creating multiple methods with same Name but different parameters is known as method overloading.
       
       *)Method Overloading Can be used to achieve same Functionality with different parameters.

       *)At the time of method overloading parameters must be different Either by length (or) Datatype.

       *)We can overload static as well as non-static methods.

       *)Method overloading can be used to achieve polymorphism. 



3.What is mean by Method Overiding?

        *)The process of Inherit the method from super class and changing It's implementation in Sub class is known as methoveriding.

        *)At the time of method overriding method signature should be same but we change definition.
     
        *)Method Overriding is used to achieve Different Implementation with same parameters.
 
          ==>We can't override Following Methods::

             *)Static 
            
             *)Private 
   
             *)Final


  Static:
         ==> We can't override static methods Because Static members are the permanent Members of the class.

  Private:
        ==>We can't Overide Private method Because Private Members are not Accessible Outside the Class.

  Final:
       ==>It's Not Possible to Overide Final method Because It will be Consider as constant method.

       ==>Method Overiding Is used to achieve the run time polymorphism.



4.What is use of final keyword?

         *)In java Final Keyword is used to create constants.

         *)Final Keyword can be used along with variable method (or) class.
    
         *)If variable is a final then we can't Re-Initialization that variable.

         *)If method is a final then we can't override that method.

         *)If class is a final then we can't Inherit the properties of that class.
