For Loop In java::-

Definition:-

    *)A for loop is a control statement used to execute a block of code repeatedly for a specific number of times.
    
    *)A for loop consists of initialization, condition, and increment/decrement expressions. The loop continues until the condition becomes false.
   
    *)A for loop is a control statement used to execute a block of code repeatedly for a specific number of times.
    
       It Contains:-
       ------------
              *)Initialization
              *)Condition
              *)Increment/Decrement


 Syntax:-

           for(initialization; condition; increment/decrement) {

                         // statements
              }



| Part       | Description    |
| -----------| -------------- |
| int i = 1 | Initialization |
| i <= 5    | Condition      |
| i++       | Increment      |
| { }       | Loop Body      |
