**1.Java Variables \&\& Datatypes::**



==>>**Variables are containers for storing data values.**



\*)A variable is a container which holds the value while the Java program is executed. A variable is assigned with a data

type.



\*)Variable is a name of memory location. There are three types of variables in **java: local, instance and static.**



**Data Types in Java:**



\*)In programming languages, data types specify the different sizes and values that can be stored in the variable or constants.



**There are the following two types of data types in Java:**



==>Primitive Data Types: **The primitive data types include boolean, char, byte, short, int, long, float and double.**

==>Non-Primitive Data Types / Wrapper class**: The non-primitive data types include Classes, Interfaces, String, Integer,**

**Boolean and Arrays.**





**byte   → 100          → 1 byte**

**short  → 20000        → 2 bytes**

**int    → 100000       → 4 bytes**

**long   → 9876543210   → 8 bytes**

**float  → 5.75         → 4 bytes**

**double → 99.9999      → 8 bytes**

**char   → 'A'          → 2 bytes**

**boolean→ true         → very small**



**for example:**



1**.String** - stores text, such as "Hello". String values are surrounded by double quotes

2\.**int** - stores integers (whole numbers), without decimals, such as 123 or -123

3\.**float** - stores floating point numbers, with decimals, such as 19.99 or -19.99

4\.**char** - stores single characters, such as 'a' or 'B'. Char values are surrounded by single quotes

5\.**boolean** - stores values with two states: true or false









**2.Declaring (Creating) Variables**

&#x20;To create a variable in Java, 

&#x20;

**you need to:**

&#x20;==>Choose a type (like **int** or **String**)

&#x20;==>Give the variable a name (like x, **age**, or **name**)

&#x20;==>Optionally assign it a value using =







3.Here's the basic syntax:



**Syntax**

type variableName = value;





**Example**

Create a variable called name of type String and assign it the value "John".

Then we use println() to print the name variable:



String name = "John";

System.out.println(name);

1.What is project in core java?



A project in Core Java typically refers to a collection of related code files, resources, configurations, and dependencies

that together make up a software application or a component of a larger system.





2.package in java?



In Java, a package is a namespace that organizes a set of related classes and interfaces. Conceptually, you can think of

packages as similar to directories or folders on your computer that group related files together.





3.What is class in java?



In Java, a class is a blueprint for creating objects (instances). A class defines a set of properties (fields) and behaviors

(methods) that the objects created from the class can have.



**Components of a Class:**

Fields (Variables): Variables that hold the state of an object.

Methods: Functions that define the behavior of the object.

Constructors: Special methods used to initialize objects.

Nested Classes: Classes defined within another class.

Initialization Blocks: Code blocks for initializing fields.
