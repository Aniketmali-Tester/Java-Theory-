Encapsulation::

1.What is Encapsulation?

       ==>The Process of binding members of the class along with class body and protecting them by using Access modifiers is known as Encapsulation.
      
       ==>In other words is the process of binding Data members and function  Members and functions members as know as encapsulation.
      
       ==>Encapsulation can be used for Data Hiding purpose.
      
        ==>In order words we secure of the members of the class with help Encapsulation.

 We can use following concepts to achieve Encapsulation.

              *)Java Bean class


2.What is Java Bean class?

        ==>The class Which Contains Private Data Members and public getters  and setters is known as Java Bean class.
        
        ==>Getters Method are used to provide read Access for private Data members.
        
        ==>Setters Methods are used to provide write Access for private Data members. 
        
        ==>It's possible to achieve Encapsulation by creating Java bean class.
