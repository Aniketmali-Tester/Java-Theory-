Object:


1.What is an object?
 
    ==>An entity having Its own state and behaviour will be considered as an object.
    ==>State Represents characteristics of an object where as behaviour represents functionality of an object.
    ==>In case of java object is a copy of non-static members.
    ==>Non-static data Members represents state of an object where as non-static function member represents behaviour of a object.
    ==>In Java object is also known as instance of the class.


                                         Object


                            State                    Behaviour
                         (Characteristics)        (Functionality)
